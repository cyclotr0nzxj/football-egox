# 三段更新版为何偏离几何预览

Pair01 的成片身份、Pair05 的成片朝向和 Pair04 新版的草地纹理均有明确画面问题。三段现有输出是案例证据，不能用文件验收通过代替画面保真结论。

## 实际送入模型的内容

三份实际推理外参与已选 CPU 预览逐项相同。相机中心相对首版的最大数值差低于 `9e-15` ViPE 单位。三段 EXO、正式先验和 GPU 原始输出的 SHA-256 都与相应记录一致。每段独立解码 49 帧；GPU 原片的 EXO 半幅逐帧最近邻全部匹配相同源索引，成片从 x=784 开始截取右侧 448 像素。CPU 预览的 25 fps 与成片的 30 fps 只影响播放时长，以下按索引比对。LoRA 的加载与融合有实际运行证据。[输入和输出核对](audit.json) · [运行审计](../logs/runtime_audit.json)

|---|---|---|

## 目前能解释的两个阶段

正式渲染的草地来自稀疏深度点。固定点大小和深度采样在近处目标视角留下大量投影空隙。Pair04 的条纹在扩散输入处已经可见。Pair05 正式先验的 F24 上半幅非暗像素只占约 1.4%，可见物体仍在正确方位。单机位无法提供遮挡区内的真实纹理。CPU 预览、正式渲染和 EgoX 生成的采样方法也各不相同。[正式渲染点半径](../../../../../records/official_renderer_geometry.py#L1064)

EgoX 把先验编码成可供去噪参考的潜变量，原始 EXO 的 RGB 和图像编码仍独立输入。GGA 给方向吻合的源像素增加注意力权重，但共享给全部时刻的候选仍参加学习注意力，且没有佩戴者身份或透视遮挡的硬门槛。Pair01 与 Pair05 的上半身筛除只作用在渲染器，原始 EXO 图像和 GGA 深度仍含两位球员。由此可以解释为什么模型有空间重新安排人物与构图，具体是哪一路条件主导要靠对照实验。[先验编码](../../../../../vendor/EgoX/core/finetune/models/wan_i2v/sft_trainer.py#L149) · [生成注意力](../../../../../vendor/EgoX/core/finetune/models/wan_i2v/custom_transformer.py#L103)

两路投影的镜头模型也确有不一致。正式 Renderer 把 Aria 12 项分别传入径向、切向、薄棱镜鱼眼公式。EgoX 用普通 OpenCV `undistortPoints` 反解同一排列的参数。在实际 56×56 射线格、448 像素名义有效圆内，用 GGA 反解并用 Aria 精确公式回投的像素误差中位为 13.1、第 90 百分位为 38.2、最大为 54.6，光心误差为零。匹配的 Aria 数值反解在同一离线检查中最大残差低于 0.001 像素。这组计算隔离了镜头方程差异，离散旋转、栅格和注意力池化未进入误差。中心视线与滚转的复算支持当前相机朝向，成片问题的因果归属仍需生成对照。[本机数值](lens-check.json) · [GGA 射线](../../../../../vendor/EgoX/infer.py#L123) · [Aria 正投影](https://raw.githubusercontent.com/facebookresearch/pytorch3d/v0.7.9/pytorch3d/renderer/fisheyecameras.py) · [OpenCV 参数格式](https://docs.opencv.org/4.x/d9/d0c/group__calib3d.html)

## 质量保证的边界

外部 Astra 适合作为固定评审流程。生成前以本机程序核对身份锚点、帧序、镜头一致性和关键物体是否确实出现在正式先验。生成后逐帧或用预设抽帧核对球、人、地面和目标朝向。逐条保留证据，出现双球、错人、方向偏移或明显条纹时拒绝交付该版。此次 Astra 只收到去标识化技术摘要。固定可用模型版本、推理强度和判据可提高评审口径的一致性。

现有 Responses API 与 EgoX 没有共享权重、射线张量或去噪步接口，Astra 质检可以拦截失败结果。要让输出更忠实，首先核对投影模型一致性和先验中的观测前景，优先保住 EXO 可见的像素与方向，再对缺测区域进行有边界的补全。实际复跑若获授权，建议先用 Pair05 单段、相同姿态、同一渲染和两次相同初始化进程，只切换射线计算方式，提前固定 F12/F24/F36/F48 对球与队友的检查。首版与更新版的批次顺序不同，全局 VAE 随机采样也可能影响画面，当前前后对照不作单因素归因。本次未开卡或重跑。

首个 `gpt-6.2-astra / max` 请求遇到传输错误。第二个收敛请求实际返回 `completed`，输入 179、输出 5,091 token。Astra 建议在受控复跑中优先统一镜头反投影和正投影，并将球员身份、球数、目标朝向和地面纹理列入独立验收。这里在未来单因素测试中冻结原正式先验的文件哈希，单独替换 GGA 射线的计算，以便判断其影响。[API 用量](../../../api_usage.json)
