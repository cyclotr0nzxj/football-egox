# Pair05 F12、F24 球可见性复核

F24 的主要问题是第三人称球掩码漏标。旧实现会按深度保留每个虚拟像素最近的源像素。F24 旧球掩码投到两套相机后，分别有 31 和 36 个候选位置被记为遮挡。其中 29 和 32 个位置选中的源像素，经回查仍是同一个球，主要来自旧掩码没有覆盖的白色、黄色花纹和边缘。近景队友挡球的解释没有得到这部分同帧数据支持。

只在 F12、F24 按第三人称 R8 原图补标可见的球面。保留旧掩码，新增 218 和 387 个源像素。两套相机沿用已有参数和深度，用同一近深度规则投影。裤腿、白鞋、草地负例仍保有原身份。强制将负例归给球的测试全部被拒绝。已有队友和标志盘的目标坐标及对应源坐标逐像素相同，RGB 也逐像素相同。草地深度调整的试验把部分真球面误选为草地，因此没有采用。

| 帧 | 标定 | 球前景像素原数 → 复划 | 新最大连通区 | 向内缩 1 像素后的球像素 | 队友像素 | 标志盘像素 |
| --- | --- | ---: | ---: | ---: | ---: | ---: |
| F12 | 名义 | 36 → 62 | 60 | 47 | 2072 | 61、38 |
| F12 | 敏感性备选 | 30 → 66 | 65 | 44 | 1558 | 57、38 |
| F24 | 名义 | 3 → 71 | 64 | 32 | 1267 | 55、47 |
| F24 | 敏感性备选 | 12 → 95 | 84 | 46 | 1069 | 54、47 |

三类目标在两帧两套标定均保有同帧源像素证据。F24 每套仍有 8 个球候选位置的深度竞争落在未确认的背景像素上，本次阈值没有跳过这些像素。放大图里球仍稀疏变形，修复仅说明前景标记可以继承现有球像素。两帧结果不足以判断连续运动的球形、真实遮挡关系或 EgoX 成片效果。

- [队友、球和标志盘同帧对照](results/projection-review.png)中彩圈仅标记位置，实体证据保留源 RGB。
- [虚拟像素球面放大图](results/projected-ball-closeups.png)放大目标图同一位置，保留稀疏点和空缺。
- [修复记录](results/repair-receipt.json)逐帧给出新增的全部源图坐标、落败位置和文件校验值。[源掩码](results/source-ball-masks.npz)同时包含修改前后数据。

在项目根目录运行，使用现有 `ffmpeg`、`ffprobe`、OpenCV、NumPy 和 Pillow。脚本写入新目录，复查冻结输入及历史输出的逐像素一致性。

```bash
pair05=runs/pair04_s0024-a800-20261121/occlusion-contact-20261122/pair05
review_root=$(mktemp -d /tmp/pair05-identity.XXXXXX)
PYTHONDONTWRITEBYTECODE=1 OPENCV_IO_ENABLE_OPENEXR=1 \
  python3 "$pair05/repair_ball_identity.py" "$review_root/results"
```
