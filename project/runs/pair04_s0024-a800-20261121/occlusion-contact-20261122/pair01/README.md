## 边界不确定性验证

固定已经重建的虚拟机位，先复现旧的逐像素标签和来源。另用可见球轮廓、近似 0.11 米球半径及地面非穿透约束为已复核的球内核提供一个可行深度。F20 等帧允许球腾空。校正保持 EXO 原射线，红鞋与其余场景的原深度不变。只校正球内核会在旧位置留下疑似同一球的边缘。在额外对照中，将球中心 9 像素内身份未知的近邻留空，并保留已核实的红鞋、球内核和队友。只显示原画面中实际采到的像素。[同帧几何对照](results/geometry-same-frame.jpg)

名义假设下 F28 的球内核投影从 38×10 像素的长条收拢到 9×16，剩 34 个直接投影像素。把假定半径在 0.10、0.11、0.12 米之间变化，三套可行的 F28 球心在 448 像素画幅中的估计横坐标约为 277、157、161 像素。F20 的球甚至在同一红鞋源点两侧翻转。因此几何只是敏感性对照，真实相对位置尚不能用其中任一候选验收。R8 像面关系是本轮可靠输出。
