# Pair05 遮挡与 Pair01 脚球关系

本轮使用本机 CPU 和冻结的 R8 数据。原始相机、RGB、深度和历史结果用作对照，Nano 留作独立评估。

## Pair05

早期遮挡审计用实例 0 统称背景。把相机内每个遮挡赢家的源索引标回到放大的 R8 F24 后，发现大部分赢家落在可见的球轮廓上。只用绿色筛草的早期实验会混进黄绿球纹，无法证明这些样本是草坪。保守重划同帧可见球缘，对照时保持相机、深度、Z-buffer 赢家和原始 RGB 逐值一致。标注对象为球的投影位置变多，球的真实可见像素原本已经进入画面。

| 帧 | 名义机位的球标签像素 | 备选机位的球标签像素 |
| --- | ---: | ---: |
| F12 | 36 → 62 | 30 → 66 |
| F24 | 3 → 71 | 12 → 95 |

两帧在两套机位下都有队友、球和标志盘的直接投影样本。F24 涉及的 31、36 个旧遮挡位置里，29、32 个来自同一球面。每套机位仍有 8 个未确认的背景深度竞争位置。复查维持原深度与 RGB。用同一目标深度赢家倒查发布版每块 16 个原像素的采样位置，F24 球直接支持由 0 增至 4 或 6。[球缘复核](pair05/results/exo-contour-review.png) · [虚拟画面对比](pair05/results/projection-review.png) · [采样对照](../egox-reuse-audit-20261122/pair05-reviewed-sampling.json)

在旧标签与固定相机、深度下，将 F24 目标采样细分至 4 倍，分别有 31、48 个原尺寸格子至少获得一个球子像素。该测量定位粗网格的竞争。用 0.11 米假定球半径重算已复划轮廓，F24 的名义机位球深约为 4.29 米，平面法约为 3.86 米。旧球缘估计为 6.28 米，说明轮廓漏标也会影响球径估深。仍保留现有逐像素深度和不确定性。[网格证据](sampling-resolution-audit.json) · [复划后深度对照](ball-depth-cues-reviewed.json)

## Pair01

F20–F27 的 R8 原图里，靠球的红鞋与这颗球之间可见间隔。F28，最近可辨红鞋像素距球心约 7 像素，与可见球半径相当，球缘贴近或重叠，三维触球未知。把不确定性直接写进每个帧的图注。虚拟相机的球深度测试沿用同一批 RGB 样本，不用估计球面填补不可见区域。改变假定半径会让 F28 的虚拟球位置明显变化，对现有相机和深度证据，R8 九帧图更适合核对脚球相对位置。[R8 九帧](pair01/results/r8-shoe-and-ball.jpg) · [测量与试验](pair01/results/shoe-ball-review.json)

## API

官方 Responses API 的 `gpt-6.2-sol / max` 用于确定局部修正和保留真实遮挡的边界。首轮达到 12,000 输出 token 上限，缩小问题后完成。实际 R8 溯源否定了把候选遮挡统一当草的假设，修正转至可见球缘来源。后续 `gpt-6.2-astra / max` 独立复核，确认同样的 RGB 画面可有更准确的语义归属，并支持把 F28 触球标为未知。两次完成请求均只提交脱敏文本。[实际用量](api-usage.json)
