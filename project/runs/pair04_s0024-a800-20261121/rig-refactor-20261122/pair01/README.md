# Pair01 独立重建和同帧验证

用 Pair01 的 R8 源视频独立重算候选相机。25 fps 的 49 个源帧维持原顺序。旧跟球外参只用于对照。同焦距重新估计地面的一列用于单独观察场地条件变化。独立候选的头位按 EXO 里观察到的红鞋脚点、二维头标、场地白线和记录机高重新估计。白鞋队友躯干及人工审核的当帧球像素用于设定候选朝向。现有 ViPE 单目深度提供观测点的初始距离。[场地白线和机高依据](../../pair01-pose-audit-20261122/README.md)

## 本次回放结论

**候选没有通过画面验收，暂缓生成。** 开场 F00、F12 分别保留 518、551 个当帧队友躯干投影像素。F20–F28 九帧均有当帧球与红鞋经过最近深度筛选后留下的像素，球为 41–49 个，红鞋为 56–91 个。停球段有效鱼眼圆仅有 4.9%–9.1% 被直接投影所覆盖，球在 F28 压成约 38×10 像素的稀疏长条，脚与球的接触关系仍无法判断。旧跟球对照和同焦距地面修正也留下明显的草地条纹和稀疏前景。

## Rig 和可见性

候选采用独立标定分析给出的名义焦距 531 像素和 1.23 米机高。先沿原 EXO 像素把 ViPE 点换到相应的新相机射线，再将原场地平面射影变换到由白线估算的新平面。地面场地、球、人物均用同一变换，保留各自的源像素。旧跟球相机也经同一坐标变换并运输局部朝向，用于同焦距敏感性对照。候选将开场目标设为队友躯干，F13–19 渐转脚下，F20–28 看当帧球和鞋，后段重新抬向队友。朝向是可复验的实验设定，光心和实际视线仍属估计。

每帧只使用同一 R8 源帧颜色、深度和身份标注，逐像素保留最近表面。未观测区域呈黑色。球标注只覆盖 F20–F28，采用保守的 4 像素内核。F28 的左球缘与红鞋在源画面紧邻或交叠，图上只用可靠的右侧内核。二维边缘接近只能支持进一步检查，无法给出三维触球距离。[球的人工复核图](ball-observation-review.png) · [原始坐标记录](ball_observations.json)

运行结果中的 `same-frame-support.npz` 每帧有两个 448×448 数组。`F##_target_label` 中 1 表示球内核，2 表示可见红鞋，3 表示白鞋队友躯干，0 表示其他或无法确认。`F##_source_index` 为当帧 784×448 EXO 行主序源像素索引，标签 0 对应 −1。数组中 F20–F28 之外的球保持未知。结果只保留直接胜出的投影，黑区和被挡区域保持零标注。
