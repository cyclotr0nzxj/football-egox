# Pair01 与 Pair05 从 EXO 重建

原成片与先验留作对照。两段的新候选从各自的 R8 画面、EXO 实例和深度、场地线与拍摄记录重新出发。虚拟头位与朝向各自估计。保留 RGB 观测的帧号、源像素索引和有效位，未观测区域保持未知。本轮只做本机检查，Nano 留作独立评估。

## Pair01 本机重建

用 EXO 场线和红鞋脚点重新估计相机与头位，结合原始真实深度统一变换场景和头部位置，开场重新朝向白鞋队友，停球朝向取同帧球鞋观测。49 帧、25 fps 的本机重投影已核验。F20–F28 九帧均有球和红鞋的源像素，球每帧 41–49 像素，但有效圆覆盖约 4.9%–9.1%，F28 的球被拉成约 38×10 像素的稀疏长条。开场可辨队友，停球段的脚球画面仍未通过。[独立重建记录](pair01/README.md) · [预览](pair01/results/reconstruction-preview.mp4) · [同帧对照](pair01/results/same-frame-comparison.jpg)

## Pair05 需要分别验证的三层

Pair05 重新从 EXO 场线、地面、红鞋支撑和人物观测估计了头位与朝向，跑出两套 49 帧本机几何。首个重建复查发现红色手部被纳入鞋点，已用佩戴者遮罩底缘限制候选鞋点。修正后名义头深从含 13.5 米的跳变收敛到约 6.8–7.3 米，这是各假设下的估计。两套场地相容的标定在 F24 只投出 3 和 12 个球像素，队友仍破碎。两套方案共享的 F12 队友源像素落点中位相差约 22 像素，F24 可见球的源像素无交集。这次重建也未通过。[两套几何对照](pair05-reset/results-sole-filtered/rebuild-comparison.jpg) · [名义预览](pair05-reset/results-sole-filtered/nominal-prior.mp4) · [投影分歧及有效位](pair05-agreement-pixels/verification.json)

F24 可进一步定位到**深度遮挡排序**。观测到的 260 个 EXO 球像素都投进两个鱼眼圆，取整后落在 34 和 48 个目标位置。最近表面筛选后只剩 3 和 12 个。被覆盖位置的获胜样本均来自球边 1–5.2 个 EXO 像素内的背景实例。这是当前单目深度所给的排序，真实哪个表面更近仍有歧义。[遮挡反例](pair05-reset/visibility-counterexample.json)

1. **EXO 几何和证据**。直接来源与几何覆盖分开记录，真实黑色物体可拥有有效位，空洞仍是未知。覆盖或像素数不能替代物体完整性。
2. **跨时间的有效条件**。旧路线从两槽扩到 13 槽，覆盖从 51/10,192 到 317/10,192，F20 当帧球仍只有 8 个入选采样。现有 25% 测试在两个混合块里经等权平均后，球有效贡献可只有约 12.5%。相同值向量下提高路由权重也可以不改变输出；正负提示两路的变化还可以在 CFG 合并中相抵。13 槽审计证明时间覆盖缺口，实际成片条件效果须再验证。[旧架构时间回放](pair05/README.md) · [候选分支合并](../pair05-attention-floor-004/staged/pair05_gga_routes.py#L216)
3. **整幅画面**。当前完整 EXO、CLIP 首帧和 EGO 先验经不同路径进入模型。旧近黑上半圈 F12 为 96.7%，F24 为 98.2%，这个量衡量解码 RGB，不能当作光栅器占用率。先验中的已观测主体应在小范围图像压缩和跨帧条件中留存。准备了只运行官方 Wan VAE 的检查入口，本机验证了输入帧、PTS、时隙和 RGB 统计，实际 VAE 编解码未执行。VAE 通过也不意味着去噪整体通过。[本机输入核验](wan-prior-file-check/verification.json) · [检查脚本](probe_wan_prior.py) · [Wan VAE 固定版时序实现](https://github.com/huggingface/diffusers/blob/v0.34.0/src/diffusers/models/autoencoders/autoencoder_kl_wan.py#L755-L773)

已实现从同帧索引导出原始 RGB 及明确的有效位。为避免把单一假设当确定观测，可以输入两套相容的相机投影，仅保留在同一目标位置、同一对象和同一源像素上一致的观测。本机负例验证真实黑色像素仍有效，源索引错配保持未知，像素锁无法改动掩码以外区域。两套假设的严格交集会放弃许多近邻像素，这个结果只说明像素级锁定条件苛刻。[导出与检查](verified_pixels.py) · [旧成片加前景像素的反例](pixel-lock-counterexample/F24-pixel-lock-counterexample.png)

下次只在目标几何可用后测生成条件。Pair01 若要求确认真实触球，需要能看清间隙的同步侧视或足以排除分离解的独立几何证据。当前单视角结果可以报告脚球像面相邻、候选视角和缺测。Pair05 先通过重新估计的跨帧几何，再用固定 Wan VAE 验证人、球和标志盘是否仍可辨。之后若要做模型测试，用相同 latent 和步数对照正负两次前向及合并后的噪声，逐次只改变一条条件，画面还需核对全幅方向和额外人球。本轮没有执行 VAE 或完整模型。

## API 独立复核

首个官方 Responses 请求返回传输错误，未提供用量。随后缩窄问题，`gpt-6.2-astra / max` 完成复核，返回 142 个输入 token、7,389 个输出 token。Astra 指出单视图触球的歧义，支持让多套可行几何给出交集证据，并把锁定像素是否正确与全局构图是否正确分别验证。API 只接收了脱敏文字。[实际用量](astra-usage.json)
