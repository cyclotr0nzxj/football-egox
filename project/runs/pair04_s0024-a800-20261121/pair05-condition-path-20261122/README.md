# Pair05 前景条件路径复查

**现有证据把疑点放到 EGO 去噪如何利用条件。** 隔离 VAE 能解出前景，B 的条件张量接线在本机复算正常，最终解码不跨 EXO/EGO。已有实际 GPU 收据只保存初始张量哈希及注意力门控样本，无法从旧文件确定前景首次没有恢复的去噪步。

## 论文与实跑代码

EgoX 把干净 EXO 潜变量放在宽度方向，用作场景上下文。已经对齐目标视角的 EGO 先验放在独立的条件通道里。GGA 通过方向相似性给自注意力加偏置。目标 EGO 从噪声演化，代码只把 EXO 半幅的更新量置零，EGO 先验中的物体没有逐步写回结果的机制。论文的多片段消融说明三种条件总体有用，单片的局部消融仍要实测。[论文 §3.2、§3.3、附录 G.3](https://arxiv.org/html/2512.08269) · [官方源码](https://github.com/DAVIAN-Robotics/EgoX/blob/43c095b552a8f09d3a81c0882491f52c5cf4e953/core/finetune/models/wan_i2v/sft_trainer.py)

| 环节 | 本轮能确认的事 |
| --- | --- |
| VAE | 008 的 49 帧 BF16 隔离验证保住 F12、F24 的队友、球和盘。这是同一冻结先验和同版本 VAE 的实测，B 条件区的实际 GPU 张量未另存。 |
| 条件拼接 | 复跑与 B 实际执行哈希一致的代码片段。替换模拟编码值仅改变两路 CFG 输入中第 20–35 通道、右侧 56 列，计 512 个预置位置。EGO 掩码为零时，这 16 条先验通道仍有值。官方公开变换器配置哈希与当时权重清单一致，EXO/EGO 第 98 列分界与 2 列 patch 对齐。 |
| 末端解码 | 执行源码的末端分支并捕获 decoder 的输入，先调用宽 98 的 EXO，再调用宽 56 的 EGO，最后拼接像素。联合解码在首帧图像嵌入准备中出现，B 已撤掉该图像加项，排除末端联合解码直接把 EXO 围网混入 EGO 的解释。 |
| GGA | 运行调用 4,000 次，专门的路由覆盖 51/10,192 个目标块。不同阶段的匹配权重与值贡献仍未保存。开放的匹配位置只能证明路径存在，无法证明它改写了该位置的去噪结果。 |
| 提示词 | 核对已封存的元数据，提示描述户外足球和正前方队友，未指定围网。 |

本机在实际运行的路由与对应投影数据上复算，F12／F24 的队友分别有 1,872／1,214 个已标投影像素，球只有 30／14 个；两个球均落在 2 个 16×16 块。F24 最密的球块也只有 11/256 个已标像素。两帧已标球块均有同物体路由。像素数对应历史冻结机位和旧掩码，属于直接投影支持口径，和先验渲染后的可见面积不同。此前两套新机位的球缘复划是另一项诊断，其像素计数不代入这里。[本机收据](conditioning-receipt.json) · [GGA 投影](../pair05-foreground-match-20261122/results/verification.json) · [VAE 实测](../egox-reuse-audit-20261122/next-step/pair05-vae-008/README.md) · [B 实测](../pair05-clip-b-20261122/result-008-66fc463f/README.md)

## 下一次优先加诊断读回

1. **先确认 GPU 真正收到的先验。** 在第一次 Transformer 调用前取出 BF16 输入实际的右侧先验通道，反归一化后单独用同一 VAE 解码，核 F12、F24 的队友、球和盘及其位置。若这一步丢了物体，先改编码或条件组装。
2. **再做同状态的短前向对照。** 冻结实际 EGO 噪声状态、时间步、EXO、先验和文本，仅开关现有的前景路由，原版 GGA 保留。两态各做正负 CFG 前向。量化 F12、F24 对应块的注意力输出和正、负及合成后的预测变化，并与同输入的数值波动比较。读图用流模型的预测干净量 x0_hat = x_t - sigma_t * v_cfg，使用该步实际 sigma，最后单独解码 EGO。首步的读数只回答该状态的响应。若后续再运行完整轨迹，记录早、中、晚的干净预测，描述最早可辨的目标或围网变化。
3. **改动位置由读数决定。** 若读回完好而路由开关未产生有意义的前景响应，可用同类短前向只扰动先验的前景区，测模型是否使用先验。当前景响应也很弱时，优先测试 EGO 去噪对可信前景的局部约束。若路由有明显响应而画面后续仍漂移，先定位响应衰减的阶段。局部引导候选还需验收围网、身份、单球、跨帧连贯和背景细节。

当前本机运行的是同哈希代码的张量接线测试、已执行路由复算及合成 flow 代数测试。变换器、编码器、调度器和解码器均用桩验证数据流，未运行真实 GPU 网络。Nano 保持独立盲评。
