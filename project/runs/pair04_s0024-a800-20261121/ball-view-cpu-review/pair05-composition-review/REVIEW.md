# Pair05 跟球镜头与重复人物复查

红鞋球员是 ViPE 实例 1，队友是实例 2。这次用了原封存的 49 个头部中心、透视参数、第三人称画面和深度。CPU 对照两侧使用同一个佩戴者上半身遮罩，唯一改动是右侧光轴抬高 10°。球的地面位置来自第三人称标注与草地平面，实拍 Nano 留作对照。

| 检查 | 现有跟球朝向 | 抬高 10° |
|---|---:|---:|
| 镜头向下角度 | 10.6–43.1° | 0.6–33.1° |
| 448 像素高画幅中的估计球位置 | y=260–270 | y=307–317 |
| 49 帧平均投影覆盖 | 35.5% | 32.1% |
| 49 帧平均上半幅非黑覆盖 | 12.1% | 5.1% |

球位在两种朝向下均保持在画内，头部中心的最大坐标差为 3.6×10⁻¹⁵ 个 ViPE 单位。抬高镜头把球放在更靠下的位置，但进一步暴露了上方缺少观测的区域。正式复现的首选候选为原跟球朝向。抬高版保留作对照，不以重抬视线推断生成效果。CPU 有效像素比例依赖取样和近处裁剪设置，只用于本次成对对比。见 [镜头对照视频](pair05-pitch-comparison.mp4) 和 [逐帧核对](verification.json)。

旧成片看似从高处俯拍，但旧外参本身装在球员头部，原瞄准队友的下倾仅约 4–8°。旧机位的本机像素标签复投影中，逐帧可见的佩戴者像素为零，旧成片仍生成出一个脱离镜头的蹲姿人物。跟球视线下，未过滤时部分帧会看到佩戴者上半身。49 个经过检查的 [分离遮罩](pair05-wearer-upper-body.zip) 全部限制在实例 1 内，保留实例 1 的下半身像素与实例 2。裸露的 EXO 图像条件一直包含现场球员，模型输出仍可能重复生成佩戴者。[原版生成与先验对照](../../four-egox-outputs-008/synced-comparison-25fps/pair05-frame-review.jpg)

若此后获准复跑，先固定现有跟球轨迹并重新渲染正式先验。渲染过滤单独读遮罩，原 ViPE 标签应参与静态、动态分类，防止把佩戴者标成背景时进入时间均值。逐帧核验球在近处、队友和鞋的可用观测。已知球心 49 帧都落在背景标签 `0`，所以还需检查移动的球有没有在背景均值中被冲淡。[静态背景过滤](../../../../records/official_renderer_geometry.py#L545) · [动态点入口](../../../../records/official_renderer_geometry.py#L724)

对照实验以相同 49 帧、固定姿态、权重、提示词和推理参数为基础，每个条件用独立单片进程和同一个种子，避免批次顺序改变 VAE 采样状态。先比较仅改变先验的两次运行。若重复人物仍在，再固定清理后的先验，单独试验屏蔽佩戴者向第一视角提供的 EXO 几何注意力键。`--in_the_wild` 在当前版本只声明了参数。几何注意力与 EXO 视频编码都是模型条件，隔离前者的作用需要实际生成对照。[GGA 输入](../../../../vendor/EgoX/infer.py#L192) · [第一视角模型条件](../../../../vendor/EgoX/core/finetune/models/wan_i2v/sft_trainer.py#L219)

人工纠偏属于这个项目已记录的虚拟机位设置。此次在既有结果和实拍对照看过后提出的调整，作为事后案例分析。原版、预先写明的候选规则和失败例一起保留；若要报告独立效果，应冻结规则后使用未看过 Nano 对照的新片段。[课程实验计划](../../../../COURSE_EXPERIMENT_PLAN.md#L49)

`gpt-6.2-astra / max` 在 16,000 输出 token 上限下返回 `incomplete`。缩小审查问题并提高到 32,000 上限后返回 `completed`，实际用量为 224 输入、5,042 输出 token。其判断支持优先保留原跟球朝向，并首先验证仅剔除先验中佩戴者上身点的成对试验。若重复人物仍出现，再单独验证 EXO 几何注意力键。也确认 Pair04 的身体正前方朝向可作为人工指定目标的案例，既有素材属于事后分析。[API 用量](../../api_usage.json)
