# Pair04 身体正前方俯视

[49 帧对照视频](artifacts/pair04_s0024-front-view-comparison.mp4) · [首中末帧](artifacts/pair04_s0024-front-view-contact.jpg) · [相机参数](artifacts/pair04_s0024-front-view-meta.json) · [校验记录](artifacts/pair04_s0024-front-view-check.json)

左列黄箭头标示身体前方的估计草地落点，中列是此前的跟球角度，右列是新的正前方俯视。两列 CPU 投影共用同一帧 EXO、ViPE 深度和遮罩规则。右列中央是近处草地，蓝色标志碟沿原来的行进路线入画，鞋和球只在部分边缘可见。第三人称只能看见部分表面，稀疏投影保留条纹和遮挡空洞，右列平均有 30.7% 的像素获得观测采样。

## 朝向依据

- 灰衣、帽子、红鞋和已锁定的 EXO 头部位置识别出同一球员。F00–24 的侧身、帽檐和脚尖大体朝第三人称画面右侧。F27–33 有摆臂和扭转，F36–44 再次明显向右跨步，F48 上背略朝远离拍摄机位的方向转。单机位无法量出末段的实际转身角度。全段用一条稳定的近似身体前向。 [球员局部观察](exo-wearer-inspection.jpg)
- 每隔 4 帧取一次 EXO 图像，在时间中位图找出四个固定蓝色标志碟。用已有固定内参把碟底接触点投到已拟合的草地面，再按球员面向的方向拟合出前向。它和 49 帧头部首尾位移在草地面上的投影只差 3.52°。此前跟球镜头的水平朝向偏离该前向 99.79–147.32°。
- 相机中心取原 49 帧封存值。每帧头部位置到草地的垂足作为近似身体地面位置，往前取 0.65 倍当帧头部高度作为对准距离，折合 0.69–0.82 ViPE 单位。这个距离是为了看清近处草地选的机位参数，对应向下 56.98°。头部垂足会受俯身影响，末段转身细节也有误差。

## 校验与复现

从 JSON 里的新外参反算相机中心，逐坐标与原轨迹的最大差值为 `7.11e-15` ViPE 单位。EXO 和本机对照均完整解码，49 帧显示时间戳逐帧一致，F00–F48 对应 `i / 25` 秒。官方先验将沿用索引 `i`，按 `i / 30` 秒导出。F00、F24、F48 已目视检查。用新目录独立复跑后，4 份交付物的 SHA-256 全部一致。Nano 没有参与。

在本目录用本机已安装的 Python、OpenCV、NumPy、Pillow、FFmpeg 复现，指定一个新的输出目录。

```bash
/usr/local/Caskroom/miniforge/base/bin/python3 -B build_pair04_front_view.py --output artifacts-replay
```

本轮交付是 CPU 投影与新轨迹。后续正式渲染需在独立目录把新相机参数交给官方 Renderer，再用新的 49 帧先验与旧 EXO 彩色、深度跑 EgoX。
