# 四段第一视角本机复查

后续复查已经新增 [Pair04 身体正前方俯视](pair04-front-view/README.md) 和 [Pair05 俯拍感及重复人物检查](pair05-composition-review/REVIEW.md)。用户确认 Pair02 使用首次未裁切成片，本页裁切项保留作对照记录。

三段新机位保留原来 49 帧红鞋球员的相机位置。以第三人称里每隔四帧的人工足球标注、约计球半径和已估计的草地平面近似球的位置，插值并平滑朝向。Pair04 后段有脚部遮挡，Pair01 的停球过程中可能短时离地，Pair05 的快速传接球有运动模糊。这些位置用来估计目光方向。Nano 只用于此前独立对照。

| 片段 | 旧镜头向下角度 | 跟球候选向下角度 | 观察 |
|---|---:|---:|---|
| Pair05 | 4–8° | 11–43° | 让视线随来回传球变化。相机仍在球员头部高度，画面可见一名对面队友和草地。 |
| Pair04 | 7–9° | 39–57° | 低头跟随同侧的带球方向，中段可见红鞋和近处球的投影。 |
| Pair01 | 4–8° | 26–62° | 来球经过脚下时压低镜头。限制快速横转后，最大相邻帧旋转约 6.8°，估计球位持续在画幅内。 |
| Pair02 | 原成片裁切 | 110 px 顶部裁切 | 49 帧保留，30 fps，输出 448×338。右上角仍有镜头暗角。 |

三个 CPU 对照在相同头部位置、相同 EXO 数据上比较旧朝向和跟球朝向。两列都去掉佩戴者从第三人称看见的外侧上半身点，保留小腿和鞋，避免把身体外表直接投进自己的机位。黄色圈和十字表示估计球位。CPU 投影只有可观测表面，保留草地条纹和空洞。后续如进行 EgoX 复跑，必须先用对应新轨迹渲染新几何先验，再检查模型是否仍生成额外人物。

三组轨迹的 49 个相机中心在数值精度内与原版一致。三段 25 fps 的 CPU 对照和 Pair02 的 30 fps 裁切均通过完整解码与逐帧时间戳检查。数据见 [球位标注](ball-anchors.json) 和 [轨迹及覆盖检查](preview-check.json)。复现脚本为 [build_ball_previews.py](build_ball_previews.py)，开始前应另存已有预览。

本轮 Responses API 的 `gpt-6.2-astra / max` 首次请求发生传输错误，第二次实际返回模型名、102 个输入 token、6,000 个输出 token，状态为 `incomplete`。本机检查据可见图像与几何记录完成。详见 [API 用量](../api_usage.json)。
