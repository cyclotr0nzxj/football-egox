# 小目标的几何采样支持

将发布代码的 EXO 几何采样位置作为基线。比较每个 16×16 格内的原位置 (3, 4, 11, 12)² 和固定均匀位置 (1, 5, 9, 13)²。每种位置都恰好 16 个像素。发布实现随后对四个双线性取样位置生成的单位方向做池化。此处只记录直接像素支持，检验进入方向计算的原像素位置能否碰到球。

使用 Pair01、Pair04、Pair05 既有的每 4 帧 EXO 球锚点，排除各段 F12、F24 与原标注为模糊或露出不完整的帧。三个布置在同一现场，由相同参与者拍摄。历史锚点是球心和估计半径，用半径的 100%、60%、35% 构造圆形近似区域。较小半径是对有效可见范围变窄的压力测试，保留全部半径和全部负例。各组公布入选数、完全漏采数、中位支持数及逐帧胜负。

另用已有 EXO 深度与此前冻结的跟球虚拟相机把整幅图投影一次。保留相同的 Aria 投影、原图数据和全部最近深度赢家，再按各源采样位置统计去重后的赢家子集。深度赢家像素是可复现的几何代理。绝对可见性仍受深度、位姿和圆形标注近似的影响。EXO 采样位置发生变化时，几何先验本身及相机不变。漏采统计仅对本来至少有一个目标投影赢家的帧定义。

另外枚举整数坐标目标中心的 16×16 种相位，用半径 1–8 像素的合成圆检查何时完全漏采，保留均匀布局反而漏采的反例。

只在 60% 半径的主要对照中，均匀位置在三个布置均减少投影后的完全漏采，并且全半径下没有新增漏采，才将替代采样纳入后续真实推理候选。仅在压力测试中改善或任何布置反向时，保留官方栅格，把直接支持数用于故障诊断。推理还须另行固定镜头、权重、RGB、提示词和种子；成片质量需用独立实拍评估。CPU 核验全程不读 Nano。
