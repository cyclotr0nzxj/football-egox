# Pair01 首版机位与朝向的本机复核

首版把虚拟镜头对着白鞋队友。停球时，球与镜头主轴相隔 95°–124°，在 F20–F28 的九帧中始终不在有效鱼眼圆内。本机用红鞋与地面的几何关系估算了另一组头部深度，单独换这一组位置也没有把球带回视野。与既有跟球朝向组合时，该段九帧都有估计球心进入有效圆。[五列图](results/pose-comparison.jpg)

## 位置与朝向分别验证

原 EXO 的 49 个标记全部位于红鞋球员的 ViPE 实例 2。目检 F00、F04 至 F48 共 13 帧，这些标记均在红鞋球员的头帽区域。首版执行元数据的 49 个相机中心，与两次历史低头或跟球候选在数值误差内一致。当前证据可以确认选的是哪个人的头部，真实头戴相机的光心位置及佩戴偏移仍缺少独立标定。[原头部标注](../multiclip-prep/pair01_s0288/exo-head-annotations.json) · [真实光心与佩戴记录](../../../records/course_validation_20261019/capture_metadata.md#L14)

作为位置敏感性对照，在每帧红鞋颜色和 ViPE 佩戴者遮罩交集中取鞋底低点，用其视线与原场地平面的交点近似脚下支撑位置，再沿原头部像素射线估计空间深度，并做五帧平滑。49 帧中 30 帧有两个分离的红色鞋候选。重算位置较首版的距离中位数为 0.088 ViPE 单位，最大 0.260。F20–F28 的差值中位数为 0.079，最大 0.190。该估计独立于头部深度采样，但沿用 ViPE 镜头和地面平面，并假定头部位于脚下支撑点附近。它适合作为局部敏感性对照，无法恢复准确的 3D 光心。

## 场地白线给出了独立的机位疑点

从 F00、F12、F24 各自拟合右侧两条场地白线，单条拟合误差为 0.29–0.78 像素。以这两条线在草地上互相垂直为假设，在 510–600 像素焦距和 0.010–0.040 的画面斜率范围内，场地消失线中点的图像纵坐标约为 200–213 像素，ViPE 给出 185 像素。即便保持旧的 565 像素焦距，名义斜率下新估计的下倾为 1.94°，ViPE 为 3.94°。[地面消失线对照](calibration/field-calibration.jpg)

以 24 mm 拍摄记录按居中裁剪估算焦距 531 像素，并采用记录中的约 1.23 米机高后，最近蓝盘水平距离为 3.47 米，四段边长为 5.50–5.96 米，与记录中约 3.6 米和 6 米在同一量级。按这套地面约束重算的头轨与同机高归一的旧头轨，距离中位数为 1.78 米。这个差异表明头部位置对场地外参敏感，实际头戴光心的误差仍未知。白线直角、蓝盘对应关系、实际焦距和机高均需独立标定，新的头轨也不能直接与旧深度混用。[校准敏感性数据和候选坐标](calibration/field-calibration.json) · [现场记录](../../../records/course_validation_20261019/capture_metadata.md#L20)

还从 Pair01 4K R8 裁后源中核对了 13 帧，使用零起始可见索引 288 加局部帧号。中心裁剪并缩至 784×448 后，与冻结 EXO 的 RGB 平均绝对差为 2.04–3.07/255。放大后可见原锚点落在帽冠，F00–F40 多数抽查帧的帽檐与脸朝下，F44、F48 明显抬头。画面不足以精确定位头戴设备光心，帽檐只用于观察头部姿态。[4K 帽部对照](calibration/head-anchor-native-review.jpg)
