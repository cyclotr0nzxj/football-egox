# Pair03 几何预览和 Nano 实拍

[同步视频](pair03-geometry-vs-nano.mp4) · [五帧对照图](pair03-geometry-vs-nano-keyframes.jpg) · [同步校验](comparison-check.json)

Nano 实拍中，白鞋队友和红鞋前方的球能同时辨认。几何预览还原了大致的俯视方向，开头能辨认队友和红鞋，但球的纹理被压成碎点或细条，后半段队友也经常只剩窄条，无法稳定地同时认出队友和球。

| 帧 | 几何预览 | Nano 实拍 |
| --- | --- | --- |
| F00 | 可辨白鞋队友和画面下方的红鞋，球在放大后呈浅色条状碎片。 | 前方可见白鞋队友下肢，球的轮廓清楚。 |
| F12 | 队友轮廓较稀疏，红鞋可辨，球未投出。 | 队友下肢仍在前方，球部分被红鞋球员的腿遮住，仍可辨认。 |
| F24 | 队友轮廓断裂，球只有一条浅色纹理。 | 队友已靠近并偏左，右侧红鞋边的球仍可辨认。 |
| F36、F48 | 队友压缩成碎条，球未投出。 | 队友在左侧，脚下的球和佩戴者的红鞋同时可见。 |

逐帧看了全部 49 帧，并在原尺寸预览中放大检查有球像素的 18 帧。F00–F07 和 F18–F27 的遮挡筛选记录同时保留了队友与球的像素，其中球有 4–83 个直接投影像素。像素存在只证明这些帧有投影支持，画面中仍难辨认完整球形。[冻结预览和逐帧像素记录](../geometry-ground-reprojection/preview-freeze.json)

视频左右使用同一可见帧号，25 fps，共 49 帧。Nano 侧按原 16:9 画幅缩放，保留整幅画面。采集同步继承约 ±1 帧的不确定性。Nano 只在预览冻结后用于对照，镜头视场和畸变的差异尚未做标定。
