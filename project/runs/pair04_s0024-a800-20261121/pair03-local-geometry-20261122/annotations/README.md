# Pair03 第三人称标注

标注使用 784×448、25 fps 的 49 帧 R8 第三人称输入。以红鞋和深色头盔辨认佩戴者，以白鞋辨认队友。wearer_head_xy 取可辨认的头部区域内点，虚拟视角由后续几何计算得出。坐标从左上角起算，x 向右，y 向下，帧从 0 起算。

- 偶数 25 帧人工查看头部、躯干、鞋贴近草地处和粗略人框。24 个奇数帧取相邻两帧的中点。鞋底点在快速动作中只能近似估计。
- 球逐帧人工查看。18 帧清楚，13 帧露出一部分，其余 18 帧遮挡或无法确认。部分可见帧的球中心根据球缘估计，另标一个可见像素供采样检查。半径 7–8 像素为近似取样窗口。
- 人框提供身份和位置的粗范围，包含背景和空隙。每帧的可见性及人工或插值来源见 JSON。头戴实拍参考未用于标注。
