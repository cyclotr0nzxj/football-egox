# 10月19日小范围足球训练：双机位采集清单

日期：暂定 2026-10-19 下午（北京时间），待小组确认｜预留约 60 分钟｜状态：计划，尚未采集

**验收目标：至少 3 条合格的双机位配对素材，每条约 20–30 秒。**“3 条”指同一动作同时有 R8 和 Nano 原片，不是总共 3 个视频文件。优先保证停球短传；三种动作不必各凑一条。后续按清晰度、完整性和遮挡程度选一小段验证。

## 到场先做这六件事

1. **固定 R8 和焦段。**三脚架架好，画面能清楚看到主角头部、双脚和球，保留少量边缘；录制中不移动、不变焦。
2. **固定 Nano。**优先稳固头戴，记录位置和朝向；胸挂如实记为胸前视角。录 5 秒走动回看，确认没有滑落或拍偏。
3. **拍设置和机位照片。**记两机帧率、尺寸、裁切/视角与防抖，以及 R8 镜头和焦段。方便时测量并记录两只标志碟的实际间距，帮助后期检查尺度。
4. **做首尾同步标记。**两机都开录，报编号，由搭档在两机可见处拍手；动作前后留几秒，结束再拍手。
5. **先拍最简单的一条。**原地接球—停球—短传，保持低强度，避免突然大幅转头或转身；头部方向要能从 R8 画面判断。
6. **立即回看两机。**确认人球清楚、头脚完整、佩戴稳定、拍手音画都在，合格后再拍其余条。

有现成平整标定板时，可额外采集下方所述标定素材；没有板也先完成短试采。现场不用测每帧相机坐标或拍摄深度图，这些在后期处理。

## 今晚准备

- [ ] DJI Nano、可靠的佩戴固定件；Canon R8、镜头、三脚架；电池、存储卡、读卡器；iPhone 备用。
- [ ] 两机分别试录并导出到电脑，确认视频能播放、音轨有声。
- [ ] 普通视频、横屏 16:9，首次试采优先统一 4K/25fps；稳定性或容量不够则统一 1080p/25fps。此前的 30fps 档仍可用，但 R8 为 29.97fps，须记录实际设置，后期按时间戳处理。关闭美颜、滤镜，不用慢动作。
- [ ] 主角穿与背景、搭档明显不同色的衣服；参与同学提前同意拍摄及课程展示。

### 两机建议设置与参数记录

以下按 DJI **Osmo Nano** 和 Canon EOS R8 核对，作为本次小实验建议，并非 EgoX 的采集硬性格式。

| 项目 | R8 | Osmo Nano |
| --- | --- | --- |
| 模式与尺寸 | 普通视频，3840×2160，16:9 | 普通视频，3840×2160，16:9 |
| 帧率 | 25.00fps（PAL）；若用 NTSC 的 30 档则为 29.97fps | 25fps；原 30fps 档也可保留 |
| 文件 | MP4，IPB Standard | 原生 MP4 / HEVC（H.265） |
| 色彩 | Canon Log、HDR PQ 关闭，使用普通色彩 | 普通色彩，暂不用 D-Log M |
| 音频 | 开启，确认拍手声可听见 | 开启，确认拍手声可听见 |
| 几何稳定性 | 三脚架，固定焦段，建议关闭 Movie digital IS，记录裁切状态 | 选定一种 FOV/去畸变模式并保持不变；稳像可用于展示，但记录具体模式 |

两机不必同编码；Nano 不必强求 H.264。原片完整保存，后期需要时另转为便于播放的 H.264/MP4 副本。25fps 是两机共同支持的采集档位，后续 EgoX 的时间采样与导出帧率另行记录。[DJI 参数](https://www.dji.com/nano/specs)、[Canon 录制尺寸与帧率](https://cam.start.canon/en/C013/manual/html/UG-04_Shooting-2_0040.html)、[Canon 编码规格](https://www.usa.canon.com/support/p/eos-r8)

室外光照充足时，可试用约 1/250 秒快门减少脚和球的拖影，以回看清晰度和曝光为准；这不是模型硬性要求。记录快门、ISO、光圈（适用时）和白平衡，自动值允许写“自动”。

拍下两机设置界面、R8 镜头型号与实际焦段、Nano 佩戴照片，以及 R8 机位高度和场地标志物位置。焦段的毫米数不能直接当作像素单位的相机内参。

如有现成的平整棋盘格标定板，可给 R8 额外录制 10–20 个清楚、角度和位置不同的板面姿态，覆盖画面中心与边缘，记录格子边长；保持正式拍摄的镜头、焦段、分辨率和裁切设置。没有标定板也先完成短试采。Nano 的电子稳像会裁切画面，开启稳像的动态录像不能未经验证便套用一套静态标定结果。[OpenCV 标定说明](https://docs.opencv.org/4.x/dc/dbb/tutorial_py_calibration.html)、[DJI 稳像说明](https://www.dji.com/nano/faq)

转码和双视角同步无需先获得相机内外参；EgoX 视角转换所需的深度、内外参、目标轨迹和几何先验是后续独立步骤。

### 摆机位

- R8 固定在场边斜侧面，主角不要小得看不清人球；用标志碟限制活动区。每条内不摇镜头、不变焦、不移动三脚架。
- Nano 优先安全稳固的头部佩戴；只有胸挂也可采，但必须记为“胸前视角”。确认能看到前方和适量地面，避免全是天空或脚。
- 光线尽量均匀，避免正对太阳。戴设备只做低强度训练，不争顶、不碰撞、不做头球。
- 搭档站在活动区边缘，尽量不遮挡主角的头、脚和球。调整机位、佩戴位置或录制模式后，重新试拍并记录新设置。

### 每条固定口令与顺序

**两机开始录像 → 报编号 → 在两机都能看到的位置拍手一次 → 留几秒 → 做动作 → 留几秒 → 再拍手一次 → 两机停止。**

可由搭档站在 Nano 前方、R8 也能看到的位置拍手。先用试录确认两机都拍到了双手接触的瞬间，且都录到拍手声。开头标记用于初步对齐，结尾标记用于检查错配或时间漂移；同设 30fps 不等于已经同步。拍手标记留在原片里，后续动作窗口避开它。

### 后期怎样对齐

1. 保留两条完整原片，读出实际帧率、每帧时间戳、时长和音轨；文件创建时间只作辅助，不作为精确同步依据。
2. 对齐开头拍手的音频峰值，再逐帧查看两机拍手接触瞬间以修正偏移。两机距声源不同，声音峰值可能与视觉同步有偏差。
3. 检查结尾标记和中间可辨认的触球事件。若开头对上而结尾错开，排查掉帧、录制中断或帧率差异，再决定是否需要带速率修正的时间映射；不能只靠删头几帧。
4. 按共同时间段裁剪并统一导出时间轴，不简单把两段相同帧号当作同一时刻。先以可见事件约 1 帧内为课程展示检查目标，实际误差和不可见事件如实记录。
5. 导出双视角 MP4、3–5 组触球关键帧，并保存两机原时间、输出时间、裁剪窗口与处理参数。时间同步不等于两视角的空间配准。

## 后续验证边界

EgoX 官方要求第三人称机位固定；模型窗口为 49 帧，exo 为 784×448、ego 为 448×448（宽×高）。采集时保留上述长原片，后续再选窗口、统一时间采样并处理尺寸，不在现场裁切。自采输入还需要深度、相机参数、目标第一人称轨迹与先验。[官方推理要求](https://github.com/DAVIAN-Robotics/EgoX#-inference)

这里的先验是通过三维重建与目标视角渲染得到的几何视频。官方自采流程提供逐帧手工标注目标视角轨迹的方法；它不是拍完两段视频即可直接运行的流程。[官方先验处理说明](https://github.com/kdh8156/EgoX-EgoPriorRenderer#-prerequisites)

Nano 实拍供质检、同步和参考对照，不能冒充 `ego_Prior.mp4`，也不能用其画面生成首帧或提示词。头戴或胸挂、视场和畸变均可能与目标生成视角不同；时间与图像平面未核验前，不计算或宣称有效的逐像素 PSNR / SSIM。选片依据采集质量，不依据生成结果好坏。

本次只准备采集清单；自采预处理、推理和定量评估均尚未验证。项目已有阶段 A 结果单独保留。
