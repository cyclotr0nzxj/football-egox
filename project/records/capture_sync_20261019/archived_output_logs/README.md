两路单独视频均为 3840×2160、25fps，输出从时间 0 开始；同一组的相同输出帧号对应同一时刻。并排预览为 1920×540、25fps，左侧 EXO/R8，右侧 EGO/Nano。视频文件合计约 1.10 GiB。

Nano 各组都从源片第 0 帧开始；第 5 组另裁掉 Nano 末尾没有 EXO 对应的 2 帧。共同区间内的同步标记保留，便于复查。

同步先用音频拍掌粗定位，再以画面中手掌接触的过渡帧校准。设备约 18 分钟的日期时间差只用于粗配对。25fps 下 1 帧为 40ms，手掌运动模糊与曝光相位带来约 ±1 帧的视觉判断不确定性；未声称亚帧精度。第 1、3、4 组首尾拍掌均可复核；第 2、5 组开头拍掌早于 Nano 起录，以结尾拍掌为主要锚点。第 2 组中段可核对球和身体移动，但 Nano 未拍到脚部接触点，不能将其算作精确触球锚点。

单路文件保留各自原有音画相对关系；并排预览使用 Nano 音轨，避免两路声音叠加。不同设备的声音到达与录音链路延迟未单独校正。

导出为逐帧裁剪后的重新编码副本，不是无损剪切：Nano 保留 HEVC 10bit，R8 使用 H.264 8bit；均保持原始分辨率与帧率，没有变速或插帧。R8 全范围转换为 BT.709 有限范围；Nano 的旋转标记已应用到像素，使导出正向播放。后续需要最高质量输入时，可按记录中的帧范围从原片重新提取。

验收通过：15 个视频全部完整解码，合计 13287 帧；每组两路和预览帧数、时长一致。抽查了开头、中间、结尾拍手及末帧的左右位置、方向和画面。10 个原文件 SHA-256、大小、修改时间复核一致。
