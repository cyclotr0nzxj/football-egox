## 目标

做一个用于研究的足球第三人称 → 球员第一人称视频 Demo。优先验证真实生成效果，不先做三维骨架展示、交互式场景或自动头部估计。Astra 自主选择技术栈、模块划分、实现顺序与排错方法；先审查和复用工作区已有原型，不为了遵守旧目录结构而过度设计。

本文件替代旧 `PROJECT_PHASE1.md` 的项目范围说明；旧文档仅供参考。与其他项目规则整合时保留有效的安全要求，不删除用户代码或数据。本包是目标说明，不是已完成的软件或 GPU 实验报告。

## 阶段 A：官方权重和官方样例复现

不训练、不微调。默认使用官方足球样例 `cmu_soccer06_6_877_925`，以及官方提供的相机轨迹、深度、几何先验和描述文本。[S1][S2]

模型使用 `Wan-AI/Wan2.1-I2V-14B-480P-Diffusers` 加官方 `DAVIAN-Robotics/EgoX` LoRA；先核对、固定实际代码与模型版本，再运行。采用官方样例配置，第一轮 seed=42；适配实例 GPU 编号，不照搬上游脚本的 GPU 6。不要静默减帧、降分辨率、量化或换模型。[S1][S3]

**完成标准：**

1. 在用户授权的云实例上，完成至少一次真实推理，得到可播放、可导出的第一人称视频。
2. 网页直观展示并同步对照「第三人称输入／实拍第一人称参考 GT／生成第一人称」，支持逐帧检查及导出对照视频；单个三路拼接视频也是可接受方案。三路播放器互不联动不算同步。
3. 核对时间与图像平面对齐后，提供基本图像指标（如 PSNR、SSIM、LPIPS）和人球位置、遮挡、闪烁的观察记录；对齐不明就标注未验证，不凑分数。保存配置、版本、日志、耗时、资源占用与结果位置。

GT 图像只用于展示和评估，不得作为生成输入、首帧或新提示词来源；官方已提供的轨迹等条件必须如实说明。先验不是 GT，也不是最终输出。一个样例只能验证管线及该案例，不代表手机视频泛化、眼动还原或完整论文成绩复现。质量差的真实结果仍应保留。

A 使用已经准备好的先验，不重新运行 EgoPriorRenderer；不下载完整 Ego-Exo4D，不实现手机视频入口。源码引用训练目录的公共组件不等于执行训练，不要盲目删除这些依赖。

## 阶段 B：足球配对数据与专项 LoRA 微调

仅在 A 的基线保存完成、用户另外授权后启动。

Ego-Exo4D 原始足球数据可按官方许可申请，官网统计为 282 个 takes、78 名参与者、14 个场地，66.97 小时为 ego+exo 多视角合计，不是纯第一人称时长，也不是可直接用于 EgoX 的训练样本数。[S4][S5]

先获取许可和元数据，再按足球任务、take UID 和需要的视角分批下载。先打通小批配对数据处理，再扩展规模。当前公开说明提供示例与训练格式，未核实到作者完整预处理训练集的直接下载入口；按“我们自行构建足球子集”规划，不能声称已经拿到作者原训练集。[S1][S5][S6]

训练样本应包含同步第三人称、实拍第一人称，以及匹配的深度、相机参数、轨迹、先验和描述。必要时参考 EgoX-EgoPriorRenderer，优先利用经核验的官方校准和轨迹；低分辨率 MP4 下载完成不等于几何处理完成。[S1][S7]

在官方 EgoX 适配器基础上继续训练，不从头训练整个基础模型。验证现有 LoRA 确实加载后再更新参数；不能默认上游训练脚本就是“继续训练官方 EgoX”。训练前后使用相同测试条件比较。

按独立录制场次划分训练、验证、测试，再切短片段；同一动作的相邻窗口和不同机位不能跨集合。核查作者原训练重合，无法确认就记录未知。禁止在同一个足球样例上训练再把同样例改善当作泛化证据。

B 的交付是：可追溯数据清单与划分、可重现微调权重、独立保留数据上的官方模型与微调模型对照，以及失败案例。训练配置、数据规模和硬件由 Agent 提案并经资源小测后确定，不预设微调一定有效。

## 云环境与协作

A 按官方要求准备单张至少 80GB 显存的 NVIDIA GPU、Python 3.10、兼容 CUDA 12.1+ 的环境。建议 CPU 8–16 核、主机内存约 128GB、数据盘总容量 250GB；后三项是规划建议，不是实测最低要求。B 官方列出的训练门槛为至少 140GB 显存且默认脚本使用多卡，不能据此认定两张 80GB 自动满足；B 单独做资源评估。[S1]

用户负责租机/费用、签署许可、首次认证、SSH 信任与密钥设置，以及最终关机。Agent 负责代码、独立环境、下载校验、获准的 GPU 任务、评估、交付和简短 `STATUS.md`。不要要求用户手填能通过终端读到的配置。

大文件直接下载到云端 `/root/autodl-tmp/football_egox/`；复用已有有效文件，缓存和环境也尽量放数据盘。安装前检查磁盘及网络，下载前列清所需文件与容量，空间不足则暂停。费用/下载/重试范围按用户本次目标提示词，不自动扩展到 B。

只连接用户给出的实例；私钥、密码和访问令牌不进入聊天、项目或日志。先实际测试 Agent 的 SSH 能力，不能把“用户本机能连上”当作“Agent 已连上”。服务默认只监听云端 `127.0.0.1`，通过 SSH 隧道查看；不公开分享。

未经明确同意不租新机、不扩容、不重装驱动、不删除已有数据、不调用付费外部 API。遵守数据许可，不将受限录像上传至第三方服务。CPU 测试、网页启动与 GPU 真推理分别报告；不编造视频、指标或人工验收。
