# 项目指令

先读 `PROJECT.md` 和用户当前目标，检查现有代码与真实云端连接能力，再自主规划并实施。当前默认阶段 A；阶段 B 只是后续范围，不能自行启动。

优先复用有效代码与已下载文件。保持官方基线、GT 隔离和实验真实性；实际运行后才宣称成功。无需照搬旧版详细实施规范。

按当前目标的下载和 GPU 重试授权执行；超出资源或权限边界才集中请求人工动作。维护简短 `STATUS.md`，交付真实结果、复现方法和未解决问题。

不读取或泄露私钥/密码/token 内容，不改计费配置、不删除用户数据。已有项目指令需合并，不覆盖无关规则。

## API 与模型额度

- 主力模型推理和技术复核优先使用现有授权的 OpenAI API key，通过官方 Responses API 调用 `gpt-6.2-sol` 或 `gpt-6.2-astra`，统一设 `reasoning.effort=max`。
- 日常模型任务尽量使用 API 额度，当前聊天主要用于必要的沟通和工具调度。需要开启多个子代理并行时，允许使用聊天套餐内的原生子代理，主力模型仍优先走 API。API 不可用时如实说明，继续可独立完成的终端和本地校验工作。
- API 只用于转换流程外的技术规划和复核。只提交最少的脱敏技术文本，密钥仅用于认证，原始素材与项目私有文件留在原工作环境。
