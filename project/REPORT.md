## 基线、条件与真实性

官方 EgoX 源码固定在 `43c095b552a8f09d3a81c0882491f52c5cf4e953`；Wan 权重 revision 为 `b184e23a8a16b20f108f727c902e769e873ffc73`；EgoX 权重 revision 为 `28b19ef9f079bf73c84b2347fe6701e8ab7f6634`。模型共 87.035 GiB，逐文件核对官方 SHA256 / Git blob ID，见 `records/model_verification.json`。镜像仅用于传输，未更换权重内容。

使用官方 exo、ego_Prior、原有 prompt、49 份深度、第三人称相机内外参、第一人称内参和 49 帧外参轨迹。完整条件及输入哈希在 `records/input_conditions.json`。没有自动估计头部轨迹，也没有把先验当作生成结果。

设置保持 seed 42、49 帧、50 步、guidance 5.0、LoRA rank 256、GGA 开启、cosine scaling 3.0，不量化、不启用 KV cache，仅将 GPU 编号从官方示例的 6 改为本实例的 0。日志确认官方 LoRA 加载并以 scale 1.0 融合，Transformer / VAE / 文本编码器使用 BF16，图像编码器使用 FP32。

推理元数据移除了 `ego_gt_path`；官方推理源码只读取 exo 与 prior，包装器也禁止 Python 层打开 GT 文件。GT 仅在对照与评估阶段读取，没有作为首帧、提示词依据或种子选择依据。官方 Python 源码未修改；外层包装只记录与检查适配器、精度和资源。

## 对齐与指标

官方三段源 MP4 实测均为 50 帧 / 20fps，官方推理截取前 49 帧并以 30fps 导出。按源帧 0–48 与生成帧 0–48 配对；保留源末帧 49，但不将其纳入本次推理或评估。`i/20` 和 `i/30` 是文件回放时间，不能直接视作独立核验过的传感器采集时间。

经核对官方 GT 预处理、输出分支和真实画面方向，按已交付的 448×448 原生目标平面直接比较。生成只提取右侧 `x=784..1231`，未做时间偏移搜索、旋转、翻转、缩放、配准、掩膜或颜色修正。三路展示中的 exo 是原始输入，并非原始模型输出左侧的 VAE 重建。

| 指标 | 结果 | 口径 |
|---|---:|---|
| 平均 PSNR | 17.479634 dB | 逐帧 8-bit RGB MSE 转 PSNR 后，49 帧算术平均 |
| 平均 SSIM | 0.638364 | RGB 通道平均，Gaussian σ=1.5，population covariance，再按帧平均 |
| GT 相邻帧 MAE | 10.916959 / 255 | 48 个相邻帧对，全 RGB 平均绝对差 |
| 生成相邻帧 MAE | 11.214577 / 255 | 同上，包含物体与相机运动，不是独立闪烁分数 |

评分使用原始官方 MP4 解码像素，发生在追加交付编码之前，包含鱼眼黑边。未额外下载 LPIPS 模型；PSNR 与 SSIM 作为本次基本指标。

**限制：** 官方样例未附可独立核验的原始传感器时间与完整标定处理链。提供的 ego K 主点为 255.5，而 448 图像中心为 223.5；官方 GGA 的硬编码畸变与旋转处理保持不变。这里确认的是交付图像的原生方向、尺寸和帧索引约定，不能据此宣称原始相机射线级标定已验证。生成的人球位置与视野偏差作为误差原样保留，未通过对齐优化评分。这些指标只描述这个样例，不代表完整论文成绩或手机视频泛化。

## 画面观察

- **场景与视角：** 球门、黄色标志盘、红衣球员和先低头再抬头的变化可辨认。生成草地更平滑、偏蓝；视野和人物尺度与 GT 不完全一致。
- **球的位置：** 0–16 帧可见脚前球；20–48 帧 GT 的球逐渐到达对方脚下，生成的球仍偏近、滞留前景，传递距离和接球关系没有准确复现。
- **人和遮挡：** 0–18 帧生成了较大面积的红色躯干、手臂和鞋，轮廓与 GT 不同，脚与球接触附近有形变。28–48 帧对方球员脚部、手臂动作弱于 GT，不能用此验证真实接触与遮挡关系。
- **连续性与闪烁：** 全部 49 帧均不同，场地与球门大体连续，缩略逐帧检查未见整屏突闪；球纹、手脚形状仍有局部变化。相邻帧 MAE 混合了运动与生成变化，不能解释为已完成专门闪烁测量。

观察依据包括全部 49 帧联系表、0/4/8…48 帧原生大小 GT/生成对照和浏览器逐帧功能检查，见 `records/output_review/`。缩略图只用于观察，不用于评分。
