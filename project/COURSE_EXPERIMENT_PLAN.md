## 实验表述与检查

- 时间同步与空间配准分开记录：同一触球时刻的双视角拼接不等于图像配准。
- 分割对象按试片选择醒目球衣或有明显颜色差异的球；固定 ROI 和规则，报告遮挡、相似颜色等失败。人工触球标注不能称为自动触球检测，局部分割不能称为完整人物分割。[OpenCV 颜色分割](https://docs.opencv.org/4.x/da/d97/tutorial_threshold_inRange.html)
- 配准实验保存真实施加的变换。在独立固定网格点上比较估计变换与真实变换的像素偏差，并记录匹配数和 RANSAC 内点数；不只报告用于拟合的内点误差。该结果明确标为“受控合成图像配准”，不声称完成 R8 与 Nano 的全画面配准。老师若要求真实双机图像配准，另用共同可见的静态平面区域尝试并报告限制。[OpenCV 匹配与单应变换](https://docs.opencv.org/4.x/d1/de0/tutorial_py_feature_homography.html)
- 生成列入展示计划；是否必须在自采素材上成功，仍需老师确认。官方样例生成不能与自采录像混成同一组对照。
- Nano 画面仅供质检、同步和参考评估，不能用作 EgoX 先验、首帧或提示词来源。自采时间及图像平面未核验前，不计算有误导性的逐像素指标。

### 第14周后续资料：自采 EgoX 这一步具体怎么解决

首轮目标是“跟随主角头部的虚拟第一视角”，Nano 仅作时间同步后的实拍参考。先核验官方目标相机的投影约定，不将它称为 Nano 的真实标定；精确复现 Nano 视场不作为首轮目标。

| 步骤 | 怎么做 | 得到什么 |
| --- | --- | --- |
| 1. 准备最短输入 | 从头部可见、动作简单的 R8 原片选连续 49 帧；记录原片时间，明确裁剪/缩放到 exo 网格的变换 | 独立 `exo.mp4`、帧时间与尺寸映射 |
| 2. 估计场景几何 | 用官方 ViPE 入口，指定固定相机和 `lyra`；初次可估计内参，有可信标定再替换 | 深度、R8 内参、重建点云及一致的坐标系 |
| 3. 标注目标轨迹 | 在 `vipe visualize ... --ego_manual` 的 3D 视图中，逐帧将虚拟相机摆在主角头部附近，调整朝向；将界面显示的外参整理入元数据 | 49 份 `ego_extrinsics`，以及明确选定的虚拟相机 `ego_intrinsics` |
| 4. 生成先验与深度文件 | 使用点云和轨迹渲染 `ego_Prior.mp4`；另将 ViPE 深度 EXR 转为 `.npy` | 第一人称几何先验、49 份浮点深度 |
| 5. 接入验收后推理 | 补全来自 R8 的描述文本，核对路径、帧、网格、坐标与投影；通过后才用现有官方权重生成 | 自采生成结果及独立记录 |

深度和 R8 内参可由软件估计，因此标定板不是首次试跑的硬前提；固定相机模式也不等于恢复了 R8 在真实球场的绝对位置。[ViPE 官方入口](https://github.com/kdh8156/EgoX-EgoPriorRenderer/blob/main/scripts/infer_vipe.sh)、[参数说明](https://github.com/kdh8156/EgoX-EgoPriorRenderer#vipe-inference-arguments)

人工轨迹是主要工作量：官方说明要求逐帧调整，工具会显示矩阵，不需手算矩阵；当前核对到的 UI 未提供现成的关键帧插值或整段轨迹一键导出。相机位置与方向依据 R8 重建及头部画面确定，不能靠观看 Nano 结果反向挑选轨迹。Nano 随人运动，一次两机标定不能替代整段目标轨迹。[手工流程与 UI](https://github.com/kdh8156/EgoX-EgoPriorRenderer/blob/main/vipe/utils/viser.py)

接入有三项必须检查：所有输入对应同一组 49 帧；RGB、深度与内参属于同一图像网格和坐标尺度；先验渲染与推理使用相同的目标相机投影。先检查第 0/24/48 帧深度叠加和渲染预览，再检查完整序列。

本次源码核对发现：推理包含 Aria 畸变和方向处理，`--in_the_wild` 在当前 `infer.py` 中仅被声明，不能自动适配 Nano；渲染器也有固定尺寸和 30fps 导出约定。不能直接复制官方足球样例矩阵、直接塞入原始 4K 深度，或将导出播放时间当作原始采集时间。首轮采用明确记录并核验的虚拟目标相机，和 Nano 先做定性比较。[推理源码](https://github.com/DAVIAN-Robotics/EgoX/blob/main/infer.py)、[渲染源码](https://github.com/kdh8156/EgoX-EgoPriorRenderer/blob/main/scripts/render_vipe_pointcloud.py)

现场只需完成固定机位、头部与球清楚、首尾同步、设置和机位记录；若方便，再补已知场地距离和标定板素材。几何估计、矩阵整理和先验渲染在后期完成。当前仅核对了流程与源码，尚未安装或运行自采预处理。
