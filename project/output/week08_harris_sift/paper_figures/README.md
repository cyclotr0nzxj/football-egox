# 第8周论文配图

三张图使用已有真实实验输出，采用 Nature 科研绘图技能组织证据与排版。它们属于中文课程研究短文，不表示已满足某一期刊的投稿规范。

| 图 | 问题与面板作用 | 实际尺寸 |
|---|---|---|
| figure1_feature_plate | F50两视角：原图提供场景，Harris响应显示局部结构强度，Harris/SIFT坐标显示保留位置分布；8个图像面板均保留完整图幅 | 180 × 86 mm |
| figure2_stability | 对同一批4张图、6种条件比较位置重复率与源点保留比例，展示全部观察值和逐图宏平均 | 180 × 110 mm |
| figure3_retention_case | EGO F200旋转45°：a/b为投影源点与已匹配目标点，c给出Ns/Nt/M，d展示两种分母对应的比例 | 180 × 122 mm |

每张图均有 PNG（300 dpi）、可编辑文本的 PDF/SVG、source data 与 QA JSON。源图像未裁边、未改变颜色、未选择性修饰。Harris 响应图按原参数复算，仅用于显示；采用逐图最大正响应归一化、对数显示与 magma 色图，不能从两图亮度比较绝对响应强弱。坐标和匹配数直接读取原始 JSON，不因作图而重新检测或更改指标。图3旋转画面由原始JPEG和记录的H重新生成，避免把有损显示JPEG作为数值输入。

图2使用全部48条原始记录，生成两个指标共96行图源数据。空心点是4张相关工作图，短横线为4图比例的算术平均。4图来自同一录制中的两个时刻和两个视角，不能作为4次独立采集；不提供统计检验或置信区间。图1仅选F50作代表性空间图示，F200仍完整包含于图2及源结果中。图3使用此前已诊断的案例，不据此估计总体效果。

## 复现

依赖：Python 3.12、OpenCV 4.11.0、NumPy、Matplotlib 3.10.8。初次绘图使用本机已有 Python 包，不改变检测器或实验结果。实际绘图版本记录于 figure_contract.json。

在提交仓库根目录运行（选择新的输出目录，保留已有正式图）：

```sh
python scripts/plot_week08_paper_figures.py \
  --results results \
  --frames-root data/frames/scene04 \
  --output paper_figures_reproduced \
  --qa-tools report/paper_figures/qa_tools
```

若目录结构不同，请把 `--qa-tools` 指向随图提供的 `qa_tools/`。该目录内的对齐工具在每次导出前读取实际渲染坐标，不影响实验检测或匹配。`--figures 1 2 3` 为默认值；该选项仅选择重绘哪张整图，不会抽样图中数值。

## 检查范围

三张图均通过渲染后面板对齐检查、PDF实际字号检查和碰撞检查。PDF最小字号为7 pt，180 mm实际宽度由PDF页面尺寸核验。逐面板检查确认标签、灰色源点和彩色匹配点、全部输入图观察值、完整画幅与方法配色一致。图3有10处数字位于柱形的几何包围区域，属于直接数值标注；没有文本相交或线条穿字。

source_preflight.json中的4项WARN已经人工解释：课程交付选择PNG/PDF/SVG而非TIFF；300 dpi满足当前插图使用；源码静态解析器把 `180 / 25.4` 误识别成180英寸，实际PDF宽度为180 mm；扫描到注释中的“seeds”产生不适用的区间提示，实际图中显示4个相关确定性输入的全部观察值，不存在随机种子总体的误差区间。最终可查 qa_review.json。
